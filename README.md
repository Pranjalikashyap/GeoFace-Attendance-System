# GeoFace Attendance System

Face Recognition Based Attendance Management System built using MERN Stack and Python.

## Features

- Face Registration
- Face Verification
- Attendance Marking
- Employee Dashboard
- Admin Dashboard
- Attendance History
- Block/Unblock Employee
- Delete Employee

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Python
- Flask
- OpenCV
