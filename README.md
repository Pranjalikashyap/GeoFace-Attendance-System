# GeoFace Attendance System

A Face Recognition Based Attendance System developed using the MERN Stack and Python Face Recognition API.

## Features

- Face Registration
- Face Verification
- Attendance Marking
- Employee Dashboard
- Admin Dashboard
- Attendance History
- Block / Unblock Employee
- Delete Employee
- JWT Authentication

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Python
- Flask
- OpenCV
- face_recognition

## Run Project

### Backend
```bash
npm install
npm start
```

### Frontend
```bash
npm install
npm run dev
```

### Python API
```bash
source venv/bin/activate
python app.py
```
